# Factory Robot Hazard Analyzer

A console-based Java application to analyze factory robot hazard risk based on:
- Arm Precision
- Worker Density
- Machinery State

## Features
- Input validation using custom exceptions
- Hazard risk calculation using defined business rules
- Modular design following OOPS principles
- Use-case-wise development using GitFlow

## Technologies Used
- Java
- Git & GitHub

## Concepts Demonstrated
- Encapsulation
- Abstraction
- Single Responsibility Principle
- Custom Exception Handling
- Clean Git branching strategy

## How to Run
1. Clone the repository
2. Compile and run `FactoryRobotHazardAnalyzer.java`
3. Provide required inputs via console
